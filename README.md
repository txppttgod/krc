# Khinkali Racing Championship

Бот и мини-приложение онлайн-чемпионата по дрифту в CarX Drift Racing 3.

- `bot.py` — бот: пилоты, клубы (до 6 пилотов), этапы, квалификация по видео, парные заезды по 2 видео,
  судьи (1 или 3, OMT), очки и таблицы, ТЗ, регламент. Работает на Render.
- `index.html` — мини-приложение (GitHub Pages): сетки как на Challonge, личный и клубный зачёт, регламент.
  Организаторы правят сетку прямо в приложении.
- `tests/test_bot.py` — проверки, GitHub запускает их при каждом изменении.

## Переменные окружения (Render → Environment)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота из @BotFather |
| `SUPABASE_URL`, `SUPABASE_KEY` | та же база, что у клубного бота; данные чемпионата лежат в своей строке `bot_state` с id `krc` |
| `OWNER_IDS` | Telegram ID владельцев через запятую (узнать — `/myid` в боте) |
| `APP_URL` | адрес мини-приложения на GitHub Pages |
| `SELF_PING` | `1` — не давать сервису засыпать (только на платном тарифе) |

Render: Build Command `pip install -r requirements.txt`, Start Command `python bot.py`.

## Как управлять

Всё в личке бота: `/menu` → «Организатор». Там этапы (создать, ТЗ, судьи, регистрация, квалификация, сетка),
регламент и «О чемпионате» (текст и фото), организаторы (только владельцы).
